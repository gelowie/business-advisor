# Write Spec — Feature Ideas from Problems

## Problem type

The user has an identified problem and wants feature or spec-level ideas that address it — not a full roadmap.

## Diagnostic questions

- What's the identified problem, specifically?
- Are there existing product constraints or prior specs to work within?

## Methodology

1. Take the identified problem as the starting point.
2. Generate feature ideas that directly address it.
3. Frame each idea at a spec-ready level of detail.

## Connects to (v1)

A generated idea can become the scoped feature in an [MVP Scope Document](../../templates/Product Management/MVP Scope Document.md).

## Deliverable

A set of feature ideas or recommendations, each traceable back to a specific stated problem.

## Requirements

- Every idea must trace back to a stated problem — no generic feature suggestions unrelated to it
