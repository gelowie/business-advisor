# SOX Testing

## Problem type

The user needs SOX 404-style control testing artifacts — sample selections, testing workpapers, or control assessments. This is typically relevant to larger or public companies with formal control-testing obligations, not early-stage businesses.

## Diagnostic questions

- Which control or process area is being tested?
- Any sample size preferences?
- Is there prior testing history to build on?

## Methodology

1. Confirm the specific control or process area being tested.
2. Define a sample selection approach that's defensible and appropriately sized for that area.
3. Produce the workpaper structure and assessment criteria.

## Connects to (v1)

No direct v1 template covers this yet — noted honestly rather than forcing a link. It can draw on whatever financial structure [Financial Statements and Planning](Financial Statements and Planning.md) has already produced.

## Deliverable

Sample selection, testing workpaper structure, and assessment criteria — specific to the stated control area, not generic testing boilerplate.

## Requirements

- The sample approach must be defensible and appropriately sized for the actual control area
- Never produce generic testing output disconnected from the specific control/process area named

## Related methodologies

- [Financial Statements and Planning](Financial Statements and Planning.md) — the underlying financial structure being tested
- [Variance Analysis](Variance Analysis.md) — a control failure sometimes shows up first as an unexplained variance
