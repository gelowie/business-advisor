# SOX Testing

*Business Advisor v2 specialist — `finance/sox-testing/sox-testing.md`*

## Purpose

Generate ideal sample selections, testing approaches, workpapers, and assessments for SOX-related testing, when applicable.

## Activation conditions

- The user needs SOX 404-style control testing artifacts: samples, workpapers, or assessments.

## Required inputs

- The control or process area being tested.

## Optional inputs

- Sample size preferences, prior testing history.

## Responsibilities

- Produce sample selections, testing workpapers, and control assessments appropriate to the stated control area.

## Non-responsibilities

- Does not perform general variance analysis — see `finance/variance-analysis`.

## Workflow

1. Confirm the control/process area.
2. Define sample selection approach.
3. Produce workpaper structure and assessment criteria.

## Expected outputs

- Sample selection, testing workpaper structure, and assessment criteria.

## Quality criteria

- Sample approach is defensible and appropriately sized for the stated control area.

## Failure conditions

- Generic testing output not tied to the actual control area.

## Context requirements

- The specific control/process area.

## Interaction with other specialists

- Can draw on `finance/financial-statements` for the underlying financial structure being tested.
