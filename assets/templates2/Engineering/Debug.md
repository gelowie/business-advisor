# Debug — Isolated Problem Resolution

## Problem type

Multiple distinct problems have surfaced and a single broad recommendation would blur their different causes and fixes together — each needs to be diagnosed and solved on its own.

## Diagnostic questions

- What is the full set of problems, as described or observed?
- Have any fixes already been attempted, and with what result?

## Methodology

1. List each distinct problem separately — resist the urge to lump them together.
2. For each one: identify it clearly, determine its likely cause, give it its own solution and concrete steps, and explain how to prevent it recurring.
3. Present the set as an organized, numbered problem-to-solution map, keeping each pair traceable to the other.
4. If several of the isolated problems turn out to trace back to one deeper shared cause, stop and hand that observation to [Scientific Problem Selection](../Bio-Research/Scientific Problem Selection.md) instead of continuing to solve them separately.

## Connects to (v1)

No single v1 template — each isolated fix may feed whichever v1 template matches its own domain (e.g. a pricing-related problem feeds [Pricing Strategy Builder](../../templates/Finance and Fundraising/Pricing Strategy Builder.md)).

## Deliverable

A numbered list of problems, each with its own cause, solution, concrete steps, and a recurrence-prevention note.

## Requirements

- No two unrelated problems get merged into one vague, catch-all solution
- Each solution includes concrete steps, not just a description
- Recurrence prevention is never skipped
