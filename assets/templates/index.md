# Template Index — how the 20 templates connect

This is the map for the base layer's (V1 / Basic) template library. Read it when a request could touch more than one template, or when you need to know what else exists nearby a template you're already using. For how to select and use a template at all, see `base-layer.md`'s "Capability selection."

Every template below has its own `## Related templates` section pointing to the others listed here — this file is the map, those sections are the roads.

## Common sequences

These aren't required chains — the base layer still has one primary owner and uses only what a given request actually needs (see `base-layer.md`'s "Ownership & support"). But these are the sequences that come up often enough to name:

- **Raising money**: Pitch Deck Outline → Cash Flow Forecast → Executive Summary Builder (for the one-pager version of the same story)
- **Entering a new market**: SWOT Analysis and Action Plan or Competitive Landscape Analysis → Market Entry Strategy → Pitch Deck Outline or Cash Flow Forecast (if it needs funding)
- **Landing a client**: Sales Discovery Call Script → Client Proposal Writer → SOW Builder → NDA Builder (if confidentiality comes up before scope is final)
- **Shipping a new product**: MVP Scope Document → Roadmap Prioritization Worksheet (for what comes after the MVP) → Pricing Strategy Builder
- **Hiring**: Job Description Writer → Structured Interview Rubric
- **Bringing on a vendor**: Vendor Selection Matrix → SOW Builder → SOP Builder (for the ongoing process once they're selected)
- **Reporting upward**: Quarterly Business Review Prep or any other deliverable → Executive Summary Builder (to compress it for a busier audience)

## Adding a new template

If a future template is added: give it the same five sections (Summary, Inputs, Deliverable, Requirements, Related templates), place it in the domain folder it belongs to, add it to the domain list above, and add at least one real related-template link both ways — a template with no related templates is a template this index has lost track of.
