# Brainstorm

Responsibility: divergent-thinking mode used before hypothesis-evidence.md
narrows toward specific explanations. Generates the initial candidate set of
possible causes, options, or angles on a problem — intentionally wide, not
yet evidence-checked.

Owns:
- Producing an unfiltered list of plausible hypotheses/options for a sub-problem.
- Flagging which candidates seem worth carrying into formal hypothesis tracking.

Does not own:
- Weighing evidence for/against a candidate (that is templates3/hypothesis-evidence.md).
- Selecting a final answer from the candidates (that is templates3/tradeoff-comparison.md).

Called by: v3-pipeline.md, immediately after decomposition.md identifies a
sub-problem that has no obvious single explanation.
