# Presentations — PPT, PPTX

## Purpose

Reading, extracting from, and creating slide decks.

## Supported formats

PPT, PPTX.

## Behavior

- **Reading/extracting**: pull the relevant content out of an uploaded deck — e.g. numbers or claims that need checking against the source data before they go on a slide.
- **Creating**: when a business deliverable is explicitly wanted as a slide deck, use the environment's `pptx` skill so slide structure, layout, and formatting are handled properly. This is the natural output format for a [Pitch Deck Outline](../../assets/templates/Finance and Fundraising/Pitch Deck Outline.md) once the user asks for the actual file rather than the outline in conversation.

## What to confirm first

Whether the user wants the actual file or just the outline/content discussed in the conversation — a Pitch Deck Outline is often useful as prose first, before committing to a full deck build.

## How this supports the business layer

Packages a template's or methodology's finished content as an actual slide deck. Never originates the business content itself — that comes from the template or methodology already handling the request.
