# Web Documents — HTML

## Purpose

Reading, extracting from, and creating HTML content.

## Supported formats

HTML.

## Behavior

- **Reading/extracting**: pull the relevant business content out of an uploaded or provided HTML file or page as context for whatever template or methodology needs it.
- **Creating**: when a business deliverable is explicitly wanted as an HTML page (e.g. a shareable report), produce clean, self-contained HTML.

## What to confirm first

Whether HTML is genuinely the wanted format, or whether a Word document, PDF, or plain conversational answer would actually serve the user better — HTML is relatively rare as a business-deliverable request compared to DOCX or PDF.

## How this supports the business layer

Feeds extracted content into whichever template or methodology needs it, and can package either one's output as an HTML page. Never the source of business reasoning itself.
